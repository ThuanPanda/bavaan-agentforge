## Workflow hàng ngày

### Khi story chuyển sang "Ready for QA"

```
Bạn: "Story TICKET-042 ready for QA.
      Generate test cases và Playwright spec."

Claude:
1. Monday MCP → fetch Story ID 042 + ACs
2. GitHub MCP → fetch PR diff (component files)
3. Check data-testid trong components
4. Generate: tests/user-profile.spec.ts + pages/UserProfilePage.ts
5. Generate: tests/factories/user-profile.factory.ts
6. Upload test case checklist to Monday sub-item

Bạn: review spec, run locally, confirm coverage
```

### Khi component thiếu data-testid

```
Claude sẽ output: scripts/inject-testids.ts
→ Gửi script này cho Frontend dev để apply
→ Frontend dev apply, push, PR cập nhật
→ QA Agent re-generate spec với testids mới
```

### Khi Playwright fail trên CI

```
Bạn: "Playwright fail trên PR #234.
      Error: [paste từ GitHub Actions artifact].
      Đây là spec file: [paste]"

Claude:
→ Phân tích root cause
→ Nếu code bug: flag cho developer
→ Nếu test issue: generate fix diff
→ Create Monday bug item với full context
```

## Cấu trúc test chuẩn (Bavaan)

```typescript
// ─── Page Object Model ─────────────────────────────────
// tests/pages/UserProfilePage.ts
export class UserProfilePage {
  constructor(private page: Page) {}
  goto = () => this.page.goto('/profile');
  nameInput = () => this.page.locator('[data-testid="name-input"]');
  saveBtn   = () => this.page.locator('[data-testid="save-btn"]');
  successMsg = () => this.page.locator('[data-testid="success-msg"]');
}

// ─── Factory (multi-tenant) ────────────────────────────
// tests/factories/tenant.factory.ts
export async function createTenantUser(opts: { tenantId: string }) {
  return prisma.user.create({
    data: {
      tenantId: opts.tenantId,
      email: `test-${Date.now()}@${opts.tenantId}.test`,
    }
  });
}

// ─── Spec file ─────────────────────────────────────────
// tests/user-profile.spec.ts
test.describe('TICKET-042: User Profile Edit', () => {
  let user: User;
  const page_obj = null;

  test.beforeEach(async ({ page }) => {
    user = await createTenantUser({ tenantId: 'tenant-test-001' });
    page_obj = new UserProfilePage(page);
    await clerkSetupForTesting(page, { userId: user.id });
  });

  test('AC-1: Name update saved successfully', async () => {
    await page_obj.goto();
    await page_obj.nameInput().fill('New Name');
    await page_obj.saveBtn().click();
    await expect(page_obj.successMsg()).toBeVisible();
  });

  // ← AC-2, AC-3... tiếp theo

  test('Tenant isolation: cannot access other tenant data', async ({ page }) => {
    const otherUser = await createTenantUser({ tenantId: 'tenant-test-002' });
    await clerkSetupForTesting(page, { userId: user.id });
    await page.goto(`/profile/${otherUser.id}`);
    await expect(page.locator('[data-testid="error-forbidden"]')).toBeVisible();
  });
});
```

## AC Coverage Validation (cuối sprint)

```
Bạn: "Sprint 23 done. Validate AC coverage cho tất cả stories."

Claude:
1. Monday MCP → fetch tất cả stories sprint 23 với ACs
2. GitHub → fetch tất cả spec files trong tests/
3. Map từng AC → test case
4. Check: mọi AC có ≥ 1 test không?
5. Check: tất cả tests đang PASS không?

Output:
  ✅ TICKET-042: 5/5 ACs covered, all passing
  ✅ TICKET-043: 3/3 ACs covered, all passing
  ❌ TICKET-044: AC-2 not covered → create test case
```
